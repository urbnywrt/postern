# Postern Slice 3 (Telegram WEB proxy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** WEB-type proxies served by telemt behind the edge's own TLS/HTTP-2 termination in three placements — shared 443 with fake TLS, dedicated `IP:443`, and co-hosted under a `base_path` behind a foreign web server — with ACME DNS-01 certificates, imported certificates, a generated decoy site, and byte-compatible WEB links.

**Architecture:** The edge terminates TLS for WEB SNIs (Go `crypto/tls` + `net/http` HTTP/2) and reverse-proxies to telemt's `transport = "web"` listener on `127.0.0.1`, overwriting `X-Forwarded-For` with the real client IP. The agent runs ACME (lego, DNS-01 with DoH propagation checks) and pushes certificate generations to the edge. The panel validates domains (A record via DoH, not Cloudflare-proxied) and renders links, including the base-path form.

**Tech Stack:** Go 1.27, `github.com/go-acme/lego/v4` (DNS-01 Cloudflare provider), existing slice-1 packages.

**Spec:** `docs/design/2026-10-04-postern-design.md` §4 (WEB links), §5.4 (WEB), §10 (import of WEB proxies).

**Depends on:** slice 2 (merged first): `internal/doh` (its Task 3) for DoH lookups, the DNS forwarder for containers, and `EdgeConfig` fields 12–13; this slice adds `certs = 11` as planned.

## Global Constraints

- All Global Constraints of `docs/plans/2026-10-04-slices-0-1.md` apply verbatim.
- telemt WEB rules (from upstream docs, binding): telemt does not terminate TLS; the whole vhost (or the whole `/<base>/` subtree) must reach telemt unchanged — no path stripping, no redirects, no splitting of endpoints; `public_addr` is the public IPv4 the domain's A record points to, port 443; `web_trusted_proxy_cidrs = ["127.0.0.1/32"]`; `web_client_ip_source = "x_forwarded_for"`; the WEB listener uses `proxy_protocol = false`, `reuse_allow = false`; secret modes `plain` (32 hex) or `dd`; `ee` unsupported; `https-lanes` requires public HTTP/2; iOS uses only `https`.
- Defaults: `carrier = "https"`, `carriers = ["https-lanes"]`; reverse-proxy timeouts ≥ 65 s (WebSocket liveness), long poll 25 s passes; max request body 2 MiB; no access logs on WEB vhosts.
- ACME: DNS-01 only (TLS-ALPN-01 is backlog); Cloudflare token scope `Zone:DNS:Edit`; TXT propagation checked **only via DoH**, with the `internal/doh` client of slice 2 (RFC 8484 wire format, IP-literal endpoints): the record must be visible at Cloudflare (`https://1.1.1.1/dns-query`) **and** at Google (`https://8.8.8.8/dns-query`), each asked through its own single-endpoint client; stale `_acme-challenge` TXT records for the domain removed before issuing; one issuance per domain at a time; all HTTP clients with timeouts (30 s); renewal 30 days before expiry; `ACME staging` switch per node for tests. Never delete any DNS record other than our own `_acme-challenge` TXT.
- Cloudflare proxied-IP detection uses the published CF IPv4/IPv6 ranges (embedded list, refreshable).

### Task 1: Edge WEB termination and http-upstream listener

**Model:** opus

**Files:** Create `internal/edge/web.go` (TLS server per tls listener for routes of kind `web`, `GetCertificate` by SNI, ALPN h2/http1.1), `internal/edge/webproxy.go` (reverse proxy), `internal/edge/certs.go` (cert store loaded from `data/certs/<domain>/{fullchain.pem,privkey.pem}`, hot reload by generation), `internal/edge/httpupstream.go` (plain HTTP listener kind `http-upstream` with `trusted_cidrs`), tests. Modify `proto/postern/edge/v1/edge.proto` (add `repeated CertRef certs = 11;` with `message CertRef { string domain = 1; uint64 generation = 2; }`) + regen.

**Requirements:** For a `web` route the edge feeds the buffered ClientHello into an in-process `tls.Server` (wrap the conn so the already-read `Raw` bytes are replayed), serves HTTP/1.1 and HTTP/2, proxies every request of the vhost to `http://<backend>` with `Host` preserved, `X-Forwarded-For` = client IP (overwrite), hop-by-hop headers stripped, `FlushInterval: -1`, WebSocket upgrade supported, no request buffering, body limit 2 MiB, no access log. Limits/counters/blacklist apply per proxy as for fake TLS. `http-upstream` listeners accept plain HTTP from `trusted_cidrs` only (others closed) and trust the incoming `X-Forwarded-For` (last hop) from those peers. Unknown cert → TLS alert `unrecognized_name`.

**Tests:** TLS client (with test CA) to a web route hits a backend that echoes `Host`, `X-Forwarded-For`, path, method, body; HTTP/2 negotiated; WebSocket echo through; long-lived streaming response flushes; cert hot reload changes the served certificate without restarting listeners; http-upstream rejects untrusted peers and preserves the `/<base>/...` path verbatim; fake-TLS routes on the same listener keep working.

**Steps:** proto + regen → tests → FAIL → implement → `bash scripts/wsl 'bash scripts/race.sh ./internal/edge/...'` → PASS → commit `feat(edge): WEB TLS termination, HTTP/2 reverse proxy and http-upstream listener`.

### Task 2: ACME manager with DoH propagation checks

**Model:** opus

**Files:** Reuse `internal/doh` from slice 2 Task 3 (no second DoH client in the module); create `internal/node/acme/manager.go`, `internal/node/acme/cloudflare.go` (zone lookup by suffix, TXT create/delete, stale cleanup), `internal/node/acme/precheck.go`, tests (lego against a local Pebble container in an `integration` test with Pebble's challtestsrv as the DNS provider stand-in).

**Interfaces:** Consumes `doh.New(endpoints)`, `(*doh.Client).LookupIP`, `(*doh.Client).LookupTXT` (slice 2); propagation asks a Cloudflare-only and a Google-only client in parallel and requires both to see the value. Produces `acme.Manager{Issue(ctx, domain, email, cred), Renew(ctx), Status(domain)}` writing `data/certs/<domain>/{fullchain.pem,privkey.pem,meta.json}` atomically (0600 key) and emitting events `cert_issued`, `cert_failed`.

**Requirements:** see Global Constraints; per-domain lock; ACME account key persisted at `data/acme/account.json`; retry once after 10 s; status exposed to the reconciler for `ProxyStatus.reason`.

**Steps:** tests → FAIL → implement → PASS → commit `feat(node): ACME DNS-01 manager with DoH propagation checks`.
