# Postern

[English version](README.md)

Postern — панель и агент ноды для развёртывания, управления и мониторинга MTProto-прокси (fake TLS и Telegram WEB) на парке серверов. Панель (Go, SQLite, встроенный веб-интерфейс) хранит желаемое состояние и отправляет его нодам по gRPC поверх mTLS; на каждой ноде агент и трафиковый edge управляют движками прокси, которые работают в контейнерах Docker.

> **Статус: pre-alpha, не готов к промышленной эксплуатации.** Интерфейсы, форматы данных и схема развёртывания могут измениться без предупреждения.

## Возможности

- **Ноды и прокси.** Fake-TLS и WEB-прокси Telegram на парке нод, общий edge для трафика на каждой ноде, движки (telemt, mtg) в контейнерах, переключаются без разрыва соединений (blue-green).
- **Выходы.** Прокси выходят через цепочки выходов: напрямую, SOCKS5 или HTTP, Xray (ссылки и подписки), WARP и Psiphon, с переключением при отказе. Psiphon пока Experimental: его переписывают на psiphon-tunnel-core, на настоящем сервере он не подтверждён.
- **Скрытое управление.** Панель может достучаться до агента ноды через порт одного из её прокси по SNI управления, известному только панели, так что у ноды нет своего видимого порта управления ([развёртывание ноды](deploy/node/README.md#hidden-management)).
- **Версии, выкатки и обновления.** Версии движков и провайдеров следуют каналу `stable` или `latest` либо закреплены; канал сдвигается выкаткой (сначала канарейка, по шагам); панель и ноды обновляются сами из подписанных релизов ([панель](deploy/panel/README.md#self-update), [нода](deploy/node/README.md#self-update-updateself), [выпуск релизов](docs/releasing.md)).
- **Статистика, диагностика и публичная страница.** Трафик, соединения и уникальные IP по прокси и нодам, страны (офлайн-база DB-IP) при [политике приватности](docs/diagnostics.ru.md#политика-ip), по умолчанию не хранящей адресов клиентов, пробы, проверки каждого звена от клиента до Telegram с исправлениями в один клик, лента проблем, журнал и необязательная публичная страница со ссылками на прокси.

## Сторонние движки

Postern не включает в себя MTProto-движки. Движки, которыми он управляет, — [telemt](https://github.com/telemt/telemt) и [mtg](https://github.com/9seconds/mtg) — отдельные проекты: Postern скачивает их бинарники со страниц релизов апстрима и проверяет контрольные суммы. Так же устроены программы, на которых работают его выходы: [Xray-core](https://github.com/XTLS/Xray-core), чьи архивы сверяются с контрольными суммами, закреплёнными в Postern, и с файлами `.dgst` его релизов, и клиент Psiphon [psiphon-tunnel-core](https://github.com/Psiphon-Labs/psiphon-tunnel-core) (GPL-3.0), который каждый релиз Postern собирает из закреплённого коммита апстрима и поставляет подписанным, вместе с предложением исходного кода по GPL ([docs/third-party/psiphon-tunnel-core.md](docs/third-party/psiphon-tunnel-core.md)). Они остаются под лицензиями своих авторов.

## Данные о странах

Страну по адресу Postern определяет по бесплатной базе IP to Country Lite от DB-IP, которую панель скачивает раз в месяц. Данные о странах: IP Geolocation by DB-IP (https://db-ip.com), CC BY 4.0
